## Project Overview
This capstone project develops an end-to-end smart city traffic intelligence solution using the Metro Interstate Traffic Volume dataset.

The project covers:
- Data analytics using SQL, statistics, probability and Power BI
- Python data cleaning, feature engineering and visualisation
- Machine learning and AI modelling
- Explainability, recommendation systems and MLOps
- Responsible and sustainable AI considerations
